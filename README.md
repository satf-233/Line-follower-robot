## 硬件

- 芯片：ESP32-S3
- 灯珠：WS2812 × 1（GPIO 38）
- 电机驱动：有 TB6612FNG × 2 的驱动板
- 电机 × 3
- 摄像头 × 1
- ...

## 环境

- ESP-IDF v5.4.4
- 依赖：espressif/led_strip ^3.0.3

## 构建

> [!WARNING]
> 在构建与烧录前，务必保证pins.h与实际连接情况一致

```bash
idf.py build
```

## 烧录

> [!WARNING]
> 在构建与烧录前，务必保证pins.h与实际连接情况一致

（使用USB转串口时）
```bash
idf.py -p COM5 flash
```
